# Source Archive Records

Store dated Markdown capture records here. Each record should follow `../RECORD_TEMPLATE.md`.

Rules:
- One record per coherent NotebookLM capture session/topic.
- Preserve the original captured answer/note and its citations.
- Use numbered parts for long captures; link all parts and state the total.
- Keep ChatGPT review in a separate section from verbatim NotebookLM content.
- Do not mark a record `checked` until it has been compared against the original NotebookLM content or export.
- Do not put confidential or identifiable patient information here.
- Do not upload copyrighted source files without permission.

No NotebookLM content has been archived in this directory yet. The first record should be created only after the learner transfers and verifies the content.
