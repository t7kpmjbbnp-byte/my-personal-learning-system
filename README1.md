MY PERSONAL LEARNING SYSTEM

A personal learning system powered by GitHub, NotebookLM, and ChatGPT.

1. System Architecture

Tool	Main Responsibility
GitHub	Store learning rules, progress, mistakes, and learning history
NotebookLM	Manage learning materials and provide source-grounded information
ChatGPT	Socratic tutor, diagnostic assessment, explanations, and practice

2. Learning Principles

* Active recall
* Spaced repetition
* Socratic questioning
* Understanding before memorization
* Continuous assessment
* Evidence-based learning

4. How to Use

1. Store learning materials in NotebookLM.
2. Use ChatGPT as a Socratic tutor.
3. Record learning progress in GitHub.
4. Track mistakes and schedule reviews.
5. Update the learning state after each session.

5. Learner Commands

* Progress
