SUBJECT LIBRARY

This directory stores subject-specific learning materials and notes.

Subject Structure

Each subject should have its own folder.

Example:

01_SUBJECTS/
├── PHARMACOLOGY/
│   ├── README.md
│   ├── NOTES.md
│   └── QUESTIONS.md
│
├── ANATOMY/
│   ├── README.md
│   ├── NOTES.md
│   └── QUESTIONS.md
│
└── MEDICAL_ENGLISH/
    ├── README.md
    ├── NOTES.md
    └── QUESTIONS.md

Rules

1. Create one folder for each subject.
2. Keep notes organized by topic.
3. Record important questions and difficult concepts.
4. Link relevant learning sources from NotebookLM.
5. Update notes as knowledge improves.
